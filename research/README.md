# research/ — исследовательские документы проекта

Порядок чтения. Две волны: **тезисная** (Ф0–Ф7, август 2026 — онтология НЗ для конференции
«Витебск-2026») и **экспериментальная** (сентябрь 2026 — нейросимвольный автоскейлер).
Пути в документах тезисной волны историчны (до рефакторинга 2026-09-04); актуальная структура
проекта — корневой [`../README.md`](../README.md), задача эксперимента — [`../CLAUDE.md`](../CLAUDE.md).
