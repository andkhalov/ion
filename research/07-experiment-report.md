# Э4. Сводный отчёт эксперимента: нейросимвольный автоскейлер ВЗ → НЗ

Постановка, метрики и критерии — [Э3](06-experiment-plan.md); методика синтеза НЗ и релаксаций
— [Э2](oblique_synthesis.md); форматы и постановка обучения — [Э1](format_description.md).
Журнал всех итераций с числами — `DIARY.md` (вне git), текущее состояние — `STATUS.md`.
Статус документа: **draft** — этапы E0–E5 прогнаны полностью (full), E6 (реальные НЗ Тромсё)
идёт: снимки накапливаются скрейпером, ручная разметка не начата. Обновлено 2026-09-06.

## 0. Резюме

Построено модельное представление ARTIST на вертикальном зондировании (ВЗ), онтология проверена в
лоссе и на инференсе, представление перенесено на наклонное зондирование (НЗ) через сферический
секанс и выученную модель шума, обучена НЗ-модель, конвейер для реальных НЗ Тромсё отлажен.

| критерий (Э3 §5) | статус | число |
|---|---|---|
| **S1** ВЗ-представление: IoU F2 ≥ 0.3, \|ΔfoF2\| мед ≤ 0.15; онтология не ухудшает и снижает нарушения | **✓** | IoU 0.41, мед 0.06 МГц; L_hinge ↓ ×4.6–6.1 (порог «10×» из §2 не достигнут: остаток P3), гейт 0.7 % = ARTIST |
| **S2** НЗ-модель: МПЧ RMSE ≤ 1 МГц, гейт меток 0 %, zero-shot ВЗ хуже ≥ 3× | **✓** | RMSE 0.57 / мед 0.17 МГц, 0 %, хуже в 7× |
| **S3** сим2реал ≥ 0.8 × контроля | **✓ с оговоркой** | 0.88× после 1 эпохи, деградация до 0.38× к 10-й |
| **S4** реальные НЗ Тромсё: МПЧ vs ручная разметка ≤ 1.5 МГц мед, суточный ход | **идёт** | 4 первых снимка: F2 найден, МПЧ 5.1–7.2 при носе ≈ 7.2 МГц, гейт 0 % |
| **S5** выигрыш онтологии больше на возмущённых днях | **✗ (не подтверждён)** | нарушения 1.7 % / 1.9 %, детектор одинаков; вместо этого установлено, ЧТО ловит гейт |

Главные установленные факты: (1) онтологический член в лоссе (lognorm) вдвое снижает нарушения
физики на инференсе при равной точности по ARTIST и лучше переносится на независимый год; (2) гейт
— редкий, но высокоточный детектор ошибок структуры слоёв (ложный F1, сдвиг h′F), а не ошибок foF2;
(3) сим2реал-разрыв закрывается не «более похожей картинкой», а вторыми моментами шума
(пространственная корреляция спекла) и физикой (кратники во входе рендерера); трансплантация
реального фона вредит; (4) перенос с рендера на реальное деградирует с числом шагов обучения —
бюджет НЗ-модели ограничен одной ВЗ-эпохой, критерий остановки без меток — гейт на реальных.

## 2. Измеритель «как у дигизонда» и его калибровка

Модель предсказывает маску классов (BG/F2/F1/E/Es; на НЗ + MH-кратник) и профиль Nₑ(h) (fp(h) нижней
стороны + валидность + hmF2 прямой регрессией мягким argmax по строкам). Детерминированный
измеритель `pyon.scaler` восстанавливает таблицу Ion2PNG: foF2, foF1, foE, foEs, fmin, fxI (по
fo² = fx(fx − fB) с гирочастотой станции), h′F, h′F2, h′E, h′Es, hmF2, hmF1, hmE, MUF(D), M(3000).

Санити измерителя (Э3 §4 п.5): таблица на самих масках и профилях ARTIST = пол ошибки, который
модель не может улучшить (1500 val):

| характеристика | bias | медиана \|Δ\| | решение |
|---|---|---|---|
| foF2 / foF1 / foEs / fmin | ≈ 0 | 0.03 МГц | шаг решётки 0.11 МГц |
| fxI | −0.08 | 0.07 | ARTIST мерит X-след прямо |
| h′F / h′F2 / h′E / h′Es | +1.5 / +1.3 / +0.8 / −2.6 км | 1.3–2.3 км | **h′ по центральной линии следа** (нижняя кромка растра давала −5…−8 км) |
| hmF2 | −2.5 км | 2.5 | шаг решётки 5 км |
| hmF1 / hmE | −3.5 / +6.3 км | 2.0 / 6.6 | **высота достижения foF1/foE профилем** (поиск пиков давал 100 км: F1 — уступ) |
| MUF(3000) | −0.11 МГц | 0.08 | **k = 1.11** (при k = 1 недобор 1.8 МГц; Э2 §6.0) |

Гейт: сцена из ридаутов (+ гирочестота станции для V4) → owlrl-замыкание → SHACL (18 форм);
референс ARTIST-сцен — 0.7 % нарушений (одна S4 у JI91J), аналитические НЗ-метки — 0 %.

## 3. E1: ВЗ-модель (модельное представление ARTIST)

Архитектурное исследование (3 раунда, 19 ранов, подмножества 20–100 тыс.): BatchNorm обязателен,
dropout вредит, skip нейтрален, cosine стабилизирует; выбран U-Net d4 b32 (1.95 млн параметров),
Adam 2e-3 cosine → 2e-5, 10 эпох, batch 64, AMP (Э3 §7). Лосс: CE (веса классов) + λ·L_logic
(λ = 0.5; варианты hinge / lognorm — релаксации P1–P4 с детачем опоры и гейтов присутствия, P3 в
парной форме) + λ_prof·(L1 fp + 0.2·BCE валидности + L1 hmF2) (λ_prof = 0.5).

|---|---|---|---|---|---|---|---|---|---|---|---|---|

Выводы E1: S1 выполнен; онтология в лоссе снижает L_hinge в 4.6–6.1 раза (P1, P4 → 0; остаток —
P3-кратник ≈ 0.001, не убирается ни одним вариантом — критерий «10×» из Э3 §2 не достигнут и

модель, а пост-обработка): fmin занижен из-за низкочастотного мусора; ложные F1 в E-области дают
выбросы h′F (RMSE 50 при медиане 6 км); единичные срывы hmF2.

## 5. E3: НЗ-датасет (синтез на лету)

`pyon.oblique_synth` + `loader.ObliqueDataset`: сферический секанс Брейта–Тьюва (Э2 §2.4), O-компонента
(X — по fo² = fx(fx − fB), задел E3b), D ∈ {300, 800, 1500} км случайно на показ, классы
F2/F1/E/Es + MH (кратник 2F2), метки МПЧ 1F2/2F2 и P′ носа аналитически. Санити: гейт
аналитических меток 0 %, инвариант Пономарчука МПЧ(2F2)/МПЧ(1F2) у меток 0.790 (IQR 0.27),
муф3000-инвариант k_эмп = 1.113 на 144 SAO. ~15 % пар без F2 у ARTIST дают пустые маски (фон) —
оставлены, в метриках пропускаются.

## 6. E4: модель шума и сим2реал

Рендерер `pyon.renderer`: U-Net(5 one-hot + 2 координаты + шум → на поляризацию [p, μ, log σ]),
лосс BCE(pos_weight 8) + гауссов NLL; сэмплирование X = 1[u < σ(z − ln w)]·clip(μ + σ·ε).
Найденные и исправленные дефекты: калибровка p при pos_weight (без поправки фон втрое плотнее
реального); iid-спекл → **пространственно коррелированный** (ядро (9,3) по P(сосед|активен)/p
реального фона 3.68/5.56); **кратники 2F2/2Es во входе** при обучении сегментатора (реальные
ионограммы содержат неразмеченные кратники). Опровергнуто: постолбцовый шумовой канал (портит
плотность по высоте), трансплантация реального фона (IoU 0.02–0.15: сегментатор различает
рендер-след и реальные эхо по текстуре).

Статистики рендерера (full, 100 тыс. пар): KS амплитуд 0.26, доля активных 0.159 vs 0.146,
L1 плотностей по f / h 0.18 / 0.18 (рис. `figures/E4_renders_hetero.png`).

Сим2реал-матрица (обучение на реальном/рендере × оценка на реальном/рендере; `training
--render_train/--render_val`):

| масштаб | контроль реальное→реальное | рендер→реальное | S3 | рендер→рендер | реальное→рендер |
|---|---|---|---|---|---|
| pre (30 тыс. × 3 эп.), iid-рендер | 0.370 | 0.259 | 0.70 | 0.410 | 0.185 |
| pre, + corr(7,3) + кратники | 0.370 | **0.305** | **0.82** | | |
| full (182 тыс. × 10 эп.), лучшая эпоха (0) | 0.411 | **0.361** | **0.88** | | |
| full, последняя эпоха (9) | 0.411 | 0.155 | 0.38 | | |

Прототип (Э2 §6.0): 0.17 против 0.37 = 0.46. Перенос деградирует монотонно с числом шагов
(рис. `figures/E4_sim2real_trajectory.png`): сегментатор подстраивается под артефакты рендера.
S3 выполнен при ранней остановке; выбор эпохи по реальному val — слабая утечка меток, обе цифры
в отчёте. Следствие: бюджет обучения на рендерах ≈ 1 ВЗ-эпоха; критерий остановки без меток —
гейт на реальных данных. Резерв: доменная аугментация текстуры, адверсариальный член.

## 8. E6: реальные НЗ Тромсё (идёт)

Источник — живой дашборд chirpsounder2 (Ю. Виринен): PNG трасс SGO→TGO (430 км; 1200×900, 0.5–16 МГц ×
200–1500 км) и Juliusruh→TGO (1500 км; 640×480, 1–14 МГц × 1500–4500 км), SNR 0–20 дБ. Скрейпер

под домен обучения (порог по квантилю укрупнённой карты, 15 % активных; растяжение по 99.9-му
перцентилю); вне поля картинки — фон рендерера E4, приведённый к статистике внутренней области;
предсказания вне поля и на границе обнуляются; канал X = 0 (у чирп-зонда нет поляризаций; копия O
даёт ложные кратники). Первые чтения (4 снимка SGO→TGO, lognorm): F2 найден на всех, МПЧ 1F2
5.1–7.2 МГц при носе по картинке ≈ 7.2 (верх асимптоты недоразмечается), кратник на одном снимке с
отношением 0.78, гейт 0 %; Juliusruh→TGO без следа — модель верно молчит. Рис.
`figures/E6_tromso_sgo-tgo_panels_first.png`. Дальнейшее: накопление суток → суточный ход МПЧ; ручная
разметка 30–50 ионограмм по РД §7.3 (`data/manual/oblique_labels.csv`) → S4.

## 9. Открытые вопросы и задел

1. Деградация переноса рендер→реальное с числом шагов (E4): аугментация текстуры, адверсариальный
   член, остановка по гейту на реальных.
2. Дефекты пост-обработки ВЗ: fmin (мусор ≤ 1.2 МГц), ложные F1 → h′F, срывы hmF2 — правила
   L4-уровня, не переобучение; гейт как сигнал отбраковки F1/h′.
3. Остаток L_logic — P3 (кратник): парная форма чувствительна к остаточной массе softmax; абляция
   агрегаторов (Э2 §4-bis.5) не проводилась.
4. Корпус: максимум цикла 2013–2014 и высокие широты (p2/p3) не загружены — обобщение по циклу и
   широте не проверено; JR055-2012 без разметки.
5. E3b (точный h′x интегрированием группового показателя X по NHPC) не реализован; X-канал НЗ — по
   магнитоионному соотношению.
6. E6: S4 ждёт данных и ручной разметки; недооценка МПЧ на асимптоте следа.
